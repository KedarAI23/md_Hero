# Changelog

All notable changes to md_Hero are documented here.

## Unreleased — md_Hero 2.0
- Establish the 2.0 architecture, source change specification, test corpus and prioritised backlog.
- Planned: versioned Document IR, provenance, OCR, stronger document structure preservation, XLSX/PPTX support and model-specific token estimation.

## 1.0
- Initial native macOS document-to-Markdown application.
- Initial support for DOCX, ODT, PDF, RTF, HTML, TXT and Markdown.
- Batch conversion, basic cleaning options and approximate token statistics.

This changelog does not imply that planned 2.0 capabilities have been implemented.
