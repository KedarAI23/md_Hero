# Test fixtures

The existing fixture files are used by the Swift test suite. Add new fixtures in format-specific subdirectories as the format corpus expands:

- `pdf/`
- `docx/`
- `xlsx/`
- `pptx/`
- `html/`

Only commit synthetic, public-domain or explicitly redistributable fixtures. For each fixture, document its test purpose, licence/source, expected structure and known limitations. Do not commit actual borrower, customer, employee or confidential regulatory documents.
